# Нашивки → торговая площадка (канон)

**Статус:** задел. Площадка ещё не сделана (`/wip/marketplace`), правила уже фиксируем.

## Смысл

Любая нашивка, которую игрок **получил** (ивент дня, BP, турнир, скрытая награда и т.д.), — это **предмет инвентаря**. Позже он сможет:

1. выставить нашивку **лотом** на торговой площадке;
2. **продать** её другому игроку;
3. **купить** чужие нашивки и экипировать их у ника.

## Сейчас vs потом

| Сейчас | Потом (маркет) |
|--------|----------------|
| `User.unlockedNickPatches: string[]` — флаг «есть id» | количественный инвентарь / экземпляры владения |
| экипировка: `User.nickPatch` = один id | то же, но только из **своего** инвентаря |
| id нашивки стабильны (`creator-event-*`, `bp-l15-keech`, …) | id **не переименовывать** без миграции |

## Правила на будущее (не ломать)

1. **Стабильные id** в каталоге `PROFILE_PATCH_OPTIONS` — ключ предмета на рынке.
2. Получение награды = **зачисление в инвентарь**, не только «открыть в UI».
3. Экипировка ≠ владение: снять с ника нашивку **не удаляет** её из инвентаря.
4. Продажа лота должна **списывать** предмет у продавца и **зачислять** покупателю атомарно.
5. Ресы в ивентах/рейтингах = **подъёмы союзников из нока** (Squad revive), не хил аптечкой.
