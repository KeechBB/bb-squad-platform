## Как вести

1. Любая правка состава (join / kick / смена главы / TG / клан-кик из фракционного списка) → **сразу** дописать блок в `## История изменений` нужного файла.
2. После серии правок обновить таблицу `## Текущий состав` (снимок с VPS) или пересобрать через `scripts/_tmp_faction_archive_build.cjs` + ручную историю.
3. Сквозная лента дня — в [`_timeline.md`](./_timeline.md).
4. Сырой dump: [`_roster_dump.json`](./_roster_dump.json) (можно перезаписывать).
