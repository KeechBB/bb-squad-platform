# Гонка фракций — канон

Легион **полностью вне** системы (техотряды).

## Окна

Эпоха: **21.11.2026 00:00 МСК**, далее каждые 7 суток (`28.11–05.12`, …).  
Стык 00:00: старое окно закрывается, новое стартует сразу.

Метрика: сумма `FactionLedgerEntry` kind=`grind` за `[start, end)`.

## Цель

Старт **400 000 B$**. После окна **лично** для фракции:

- план выполнен → цель × **1.05**
- план не выполнен → цель × **0.95**

Без потолка/пола. ±5% только от гринда, не от grace/трансфера.

## Провал → grace 24ч

1. Письмо-итог в 23:59:59 / при закрытии окна.  
2. Красный таймер на вкладке **Трансферы** (рядом с составом).  
3. Любой **успешный исходящий** трансфер (игрок ушёл из состава) → `exempt`, автоштрафа нет.  
4. Иначе: случайный **MEMBER** (не глава/зам) → кик → свободный агент → СРИ в другую фракцию.

### Резерв

- В резерве **до** закрытия окна → защищён (не выставить / не автокик).  
- Ушёл в резерв **после** 00:00 закрытия → защита не действует.

### СРИ-бан

После автоштрафа нельзя вернуть через СРИ в ту же фракцию (только обычный трансфер).  
Если системой выкинут из всех 5 пехотных — баны сбрасываются.

## Письма

| Когда | От кого | Суть |
|-------|---------|------|
| День 1 | Скрытый источник | План X B$, иначе потеря человека |
| Вторник | Скрытый источник | Темп ок / отстаёте (рандом текст) |
| Финал | Гонка фракций | Выполнили / grace |
| Exempt / force | Гонка фракций | Спасение или потеря + причина жертве |

## Тик

`POST /api/cron/faction-race` (loopback / `x-bb-faction-race-cron: 1` / `CRON_SECRET`).  
Скрипт: `scripts/publish_faction_race_cron.sh` — раз в 5 минут.
