# Гонка фракций — канон

Легион **полностью вне** системы (техотряды).

## Окна

Эпоха: **21.11.2026 00:00 МСК**, далее каждые 7 суток.  
Закрытие окна: вместе с **«Закрыть тренировку»** в последнюю ночь недели (обычно суббота); иначе автоматом в **01:00 МСК** (хвост ночного гринда).

Метрика: гринд + ночные ставки в ledger за `[start, end)`.

## Цель

Старт **800 000 B$** (с окна после 21.11, вместе с ×2 гринда). Первое окно было на 400 000. После каждого окна **лично** для фракции:

- план выполнен → цель × **1.05**
- план не выполнен → цель × **0.95**

Без потолка/пола. ±5% только от гринда, не от отсрочки/трансфера.

## Провал → отсрочка 24ч → аукцион

1. Письмо-итог при закрытии окна: план не выполнен, выберите игрока на аукцион.  
2. Красный таймер на вкладке **Трансферы** / **Гонка** (отсрочка 24ч).  
3. Штаб выбирает **MEMBER** (не глава/зам) на аукцион по рыночной цене (`20 000 + гринд`) — блок в **Трансферах** и на **Гонке**.  
4. Нельзя выставить игрока с явкой **&lt; 2 TR-дней за 7 суток** (модалка «онлайн ниже»).  
5. Не выбрали до конца отсрочки → система выставляет **случайного** MEMBER (приоритет явки ≥2).  
6. Любой **успешный исходящий** трансфер (игрок ушёл из состава) → `exempt`, автоштрафа нет.

### Резерв

- В резерве **до** закрытия окна → защищён (не выставить / не автоаукцион).  
- Ушёл в резерв **после** 01:00 закрытия → защита не действует.
