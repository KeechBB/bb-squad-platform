# Гонка фракций — канон

Легион **полностью вне** системы (техотряды).

## Окна

Эпоха: **21.11.2026 00:00 МСК**, далее каждые 7 суток.  
Закрытие окна: **после последней TR** — в **01:00 МСК** (хвост ночного гринда 21:00–01:00). Календарный стык 00:00 + 1ч.

Метрика: гринд + ночные ставки в ledger за `[start, end)`.

## Цель

Старт **800 000 B$** (с окна после 21.11, вместе с ×2 гринда). Первое окно было на 400 000. После каждого окна **лично** для фракции:

- план выполнен → цель × **1.05**
- план не выполнен → цель × **0.95**

Без потолка/пола. ±5% только от гринда, не от grace/трансфера.

## Провал → grace 24ч → аукцион

1. Письмо-итог при закрытии окна: план не выполнен, выберите игрока на аукцион.  
2. Красный таймер на вкладке **Трансферы** / **Гонка** (grace 24ч).  
3. Штаб выбирает **MEMBER** (не глава/зам) на аукцион по рыночной цене (`20 000 + гринд`).  
4. Не выбрали до конца grace → система выставляет **случайного** MEMBER сама.  
5. Любой **успешный исходящий** трансфер (игрок ушёл из состава) → `exempt`, автоштрафа нет.

### Резерв

- В резерве **до** закрытия окна → защищён (не выставить / не автоаукцион).  
- Ушёл в резерв **после** 01:00 закрытия → защита не действует.

## Письма

| Когда | От кого | Суть |
|-------|---------|------|
| День 1 | Скрытый источник | План X B$, иначе потеря человека |
| Вторник | Скрытый источник | Темп ок / отстаёте (рандом текст) |
| Финал | Гонка фракций | Выполнили / grace |
| Exempt / force | Гонка фракций | Спасение или потеря + причина жертве |
