## v. 1.1.183 — 19.10.2026 · Ночной патч: меню, списки, Battle Pass, RP

**Анонс (в чат):**

```
Beta v1.1.183
https://bb-squad.ru

Ночной патч — коротко:

ДОБАВИЛИ
• Удобное меню: Кланы и Тренировка — выпадающие списки (меньше кнопок в шапке)
• Пагинация длинных таблиц (КВ, тренировки, рейтинг паблика, админка) — страница не «тянется» бесконечно
• Battle Pass: топ-10 как на главной, первые трое с медалями
• Автопроверка тикетов техники после каток + Telegram всегда пишет ОК/FAIL; бот может сам чинить часть ошибок
• Резерв/выходной в админке — через окно, не ломая список

УБРАЛИ
• Карту игроков из шапки (теперь внутри страницы клана)
• Отдельные кнопки КВ / Поиск КВ / Админ / Выйти из шапки (всё в выпадающих меню)
• В Battle Pass — лишние подписи «Значок / Рамка / …» и пагинацию рейтинга
• Двойной скролл в КВ и тренировках (остался один, как у рейтинга паблика)

ПОЧИНИЛИ
• Leopard 2A6/2A7 в RP = 15 тикетов (было криво на части каток)
• Журнал: сверху свежие записи; падение админки из‑за битого HTML
• Кланы: отступы, сортировка, щель под «Мой клан»
• Steam ID в админке больше не переносится на две строки
• Фильтры в календаре КВ ровной высоты
```

### Что добавлено
1. **Шапка сайта** — раздел **Кланы**: наводишь → Список кланов / Клановые войны / Поиск КВ. Раздел **Тренировка** → Тренировочные матчи / Тренировка стрельбы. Справа только ник → Профиль / Админка (если есть) / Выйти.
2. **Листание таблиц** — длинные списки режутся по страницам: рейтинг паблика и рейтинги игроков по 50; календарь КВ по 15; матчи тренировок по 20; в админке: пользователи и посещаемость по 50, резерв по 20, логи обновлений по 30.
3. **Battle Pass** — блок «Топ-10 прохождения» с золотом/серебром/бронзой у первых трёх (как топы на главной); карточки наград чуть компактнее.
4. **После каток** — проверка, что техника в RP посчитана по таблице Squad; в Telegram всегда приходит итог ОК или FAIL; часть FAIL бот может поправить сам.
5. **Админка** — резерв и выходной через всплывающее окно; карта игроков — вкладка на странице клана.

### Что убрано
1. Пункт **«Карта игроков»** из верхнего меню.
2. Отдельные кнопки **Админ** и **Выйти** рядом с ником (переехали в меню по нику).
3. В Battle Pass — подписи типа «Значок / Рамка / Цвет ника / Медаль» под карточками и листание всего списка игроков (остался только топ-10).
4. **Два скролла** справа на страницах КВ и тренировок — остался один скролл всей страницы.

### Какие баги пофикшены
1. **Техника в RP** — Leopard 2A6/2A7 и похожие кейсы снова по правильным тикетам (15), плюс контроль после каток.
2. **Журнал действий** — порядок свежие сверху; админка больше не падает на «битом» ответе сервера.
3. **Кланы** — ровные отступы, сортировка по алфавиту/численности, лишний зазор под блоком «Мой клан».
4. **Админка · Steam ID** — длинный номер влезает в одну строку.
5. **Календарь КВ** — поля «год / месяц / поиск» одной высоты, вёрстка не «скачет».
