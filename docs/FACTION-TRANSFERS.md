# Трансферы фракций · Черничный Доллар (B$)

Канон на **16.11.2026**. Код: `src/lib/blueberryDollar.ts`, `src/lib/factionTransfers.ts`.

Не путать с **BBC** (монеты платформы / маркет).

---

## Валюта

- Знак: **B$** (в UI — фиолетовый `$` с двумя полосками, `<BdMark />`).
- Баланс лежит на **казне фракции** (`Faction.blueberryBalance`), не на личном аккаунте.
- Движение казны: `FactionLedgerEntry` (grind / transfer_in / transfer_out / admin_adjust).

---

## Гринд → казна

### Когда капает

- Только серверы **TR1–TR5**, матч `kind=TRAIN`.
- Матч уже **залит** в статистику тренировок (`publishedAt` + `legacyId` + строка в `ProfileMatchLine`).
- **Старт экономики:** Fool's Road AAS **16.11.2026 21:33 МСК** (`legacyId=16-foolsroad`).
  Всё раньше этой катки **не считается** (даже другие карты того же дня).
- Не считается: паблик, FCL/srv, КВ, незалитый коллектор.
- Начисление идемпотентное: `sourceKey = grind:{matchId}:{userId}`.
- Если в `CanonMatchPlayer` нет `userId` — резолв по нику / steamName + backfill.

### Тарифы (линейно, потолка за катку нет)

| Действие | B$ |
|---|---|
| Убийство | **+85** |
| Рес | **+110** |
| Урон (стата `dmg`, в т.ч. по технике) | **+0,12** / ед. |
| Уничтожение техники | **+450** |

```
B$ = kills·85 + res·110 + dmg·0.12 + vehicleKills·450
```

Константы: `GRIND_RATE_*`, `GRIND_START_AT_MS`, `isGrindEligibleMatch()`.

## Оценочная стоимость игрока (рынок)

### Базовая формула

```
база 22k
+ явка TR 14д (до ~40k)
+ вклад боя 30д (киллы/ресы/ноки/матчи, внутр. вклад до 85k)
× KD (0.75…1.65)
× роль (SL 1.55, medic 1.42, LAT/AT 1.35, AR/MG 1.2, rifle 1.0, …)
× дефицит роли во фракции (critical 1.45 / thin 1.22 / surplus 0.88)
× свежесть lastSeen
→ округление до 500
→ пол 15 000, потолка нет
```

### Бонус гринда

К оценке **плюсуется**, сколько B$ игрок принёс проводками `kind=grind` (сумма по `userId`), **округление до 1 000**:

```
оценка = max(15_000, формула) + round(grindBrought / 1000) · 1000
```

Пример: принёс 1 233 → **+1 000**; 1 760 → **+2 000**.

### Доска

- Выставлять нельзя ниже **80%** оценки (`TRANSFER_MIN_ASK_RATIO`).
- Абсолютный минимум ask: **5 000** B$.
- **Комиссия 1%** от ask списывается с казны **сразу при создании лота** (`listing_fee`). При снятии лота **не возвращается** — плата за удержание игрока на аукционе.
- Для сделок состав фракции ≥ **30**.
- Лок после сделки: **14** суток.

Типы оферов: **BUY** / **SWAP** / **SWAP_CASH** (игрок + доплата).
